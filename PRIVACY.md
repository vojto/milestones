# Privacy Policy

**Milestones** collects nothing.

The app has no account, no sync and no server. It makes no network requests of
any kind: there is no analytics, no crash reporting, no advertising and no
third-party code that phones home. Nothing you type into it is sent anywhere,
because there is nowhere for it to be sent.

Everything you enter — the names of your milestones, their colors and their
dates — is written to a single file, `milestones.json`, inside the app's own
folder on your Mac. That file is yours. Nobody else, including the developer,
can read it.

Deleting the app deletes the file with it.
